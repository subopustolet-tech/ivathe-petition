# Петиция «Снять нахуй Ivathe с VIP?»

В комплекте: `index.html` (страница), `server.js` (API и сервер), `package.json`. В отличие от автономного HTML, голоса сохраняются на сервере в `data/votes.json`; повторный голос с того же введённого @username отклоняется. Публичные посетители видят только общую статистику, админ после входа — список ников и ответов.

## Важно
- Введённый Telegram-ник **не подтверждает личность**. Чтобы доказать, что человек владеет аккаунтом, нужна авторизация через Telegram Login или Telegram-бот.
- Не публикуй пароль администратора и не вставляй его в HTML. Установи его в переменных окружения хостинга.
- Для постоянного хранения JSON-файла выбери хостинг с постоянным диском (persistent disk) и задай `DATA_FILE` на этом диске. На бесплатном хостинге файловая система может очищаться при перезапуске/деплое.
- Это шуточная петиция, не связанная с Twitch/Steel/Ivathe.

## Локальный запуск
Нужен Node.js 20+. В папке приложения выполни:

```bash
ADMIN_PASSWORD='замени-на-длинный-случайный-пароль' npm start
```

Открой `http://localhost:3000`. Для внешних голосов приложение должно быть размещено на хостинге, доступном по HTTPS.

## Размещение на Render (пример)
1. Загрузи файлы в новый приватный репозиторий GitHub.
2. На Render создай **Web Service** из репозитория. Build command можно оставить пустым; Start command: `npm start`. Runtime: Node.
3. В Environment добавь `ADMIN_PASSWORD` — случайный пароль длиной 12+ символов.
4. Подключи Persistent Disk и укажи `DATA_FILE` как путь внутри диска, например `/var/data/votes.json` (проверь точку монтирования диска в настройках Render).
5. После deploy открой выданный Render URL и проверь тестовый голос и вход администратора.

## Ограничения текущей версии
- Один голос на один введённый username, но пользователь может написать чужой ник.
- Хранение — JSON-файл; подходит для небольшого шуточного опроса, не для большого публичного сервиса.
- Админ-сессия действует до 8 часов и хранится в памяти сервера.
